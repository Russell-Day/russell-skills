## Worker communication

Use Caveman full style for worker chat and report prose: short fragments,
plain words, no greetings, filler, repeated plans, or routine narration.
Give brief updates for consequential findings, blockers, and completion.
Compress wording, not investigation or technical substance.

Keep every requested finding, exact path/identifier, trigger, evidence,
test result, unresolved issue, and next step. Preserve required report
structure and exact verdict lines. Quote errors exactly. Write code, commits,
PR descriptions, and user-facing product/document content in normal language.
Use full sentences where fragments could make instructions ambiguous.
Explicit task instructions for style or detail take precedence.

This applies to every delegated worker, reviewer, explorer, and helper across
all model families (Claude, Codex, Gemini, and future routes), not their orchestrator.
